# baccaratmaker

모바일 브라우저에서 바로 실행할 수 있는 바카라 마틴 진행 페이지입니다.

## 기능

- 배팅방법 선택 → 금액 세팅 → 게임 진행의 3단계 구조
- 지원하는 배팅방법
  - **슈퍼마틴**: 패배 시 급상승(1,3,7,15...), 승리 시 그 판 배팅금액 전액 이득
  - **일반마틴 (Martingale)**: 패배 시 2배 증가(1,2,4,8...), 승리 시 손실 회복 + 1유닛 이익
  - **파롤리 (Paroli)**: 승리 시에만 2배 증가, 3연승 또는 패배 시 1유닛으로 복귀
  - **1-3-2-6 시스템**: 승리마다 1→3→2→6 배수로 배팅, 4단계 완주 또는 패배 시 복귀
  - **달랑베르 (D'Alembert)**: 패배 시 1유닛 증가, 승리 시 1유닛 감소
- 시작금액, 배팅 단위 금액, (마틴 계열은) 마틴횟수 입력— 시작금액/1마틴 금액은 서로 자동 계산
- 목표금액 입력(기본값 = 시작금액 + 1유닛 금액×10), 총 금액이 목표금액 이상이면 자동 종료
- 카드 셔플 애니메이션 뒤 `플레이어` 또는 `뱅커` 랜덤 생성
- `승리`, `패배`, `TIE`, `SUPER6` 버튼으로 판정 처리
  - TIE: 배팅금액·단계 유지, 카드만 재선택
  - SUPER6: 승리 판정이지만 수익은 배팅금액의 50%만 반영
- 진행 기록 누적 표시
- 진행 종료 시 판 횟수, 시작금액, 총 수익, 총 금액 요약 표시

## 배포

GitHub Pages 기준으로 루트의 `index.html`을 바로 열면 됩니다.

## 자동 배팅법 선택 (/2 · 2/index.html)

첫 배팅금액(1,000~10,000, 1,000단위) · 총 시작시드(50,000~400,000, 50,000단위) · 판수(10/20/30/60판)를 고르면, 9개 배팅법(마틴 6종 + 파롤리·1-3-2-6·달랑베르)의 목표달성 확률 TOP 10과 파산 확률 낮은 TOP 10, 달성−파산 차이 TOP 10, 파산 1% 미만 중 달성 TOP 10이 나오며(PC는 4열 가로 배치), 배팅법을 누르면 그 방법으로 게임이 시작됩니다. 목표수익은 항상 첫 배팅금액×4입니다.

- 통계: 80개 조합 × 9개 배팅법 각 1,000만 회 시뮬레이션 (10·20·30·60판컷을 같은 시행에서 동시에 집계)
- 데이터 재생성: `node sim/simulate.js` — `sim/autobet-data.json`을 만들고 `2/index.html`의 데이터 블록을 자동으로 갱신합니다.

## 자동검증

두 페이지(메인 · /2)의 게임 화면 우측 상단 "자동검증" 버튼을 누르면 **실제 카지노처럼 6덱(312장)을 섞은 슈에서 카드를 한 장씩 나누며** 게임이 끝날 때까지 자동으로 진행합니다.

- 슈를 섞고 첫 카드를 공개해 그 숫자(A=1, 그림=10)만큼 소각합니다. 컷카드는 슈 끝에서 7번째 카드 앞이고, 닿으면 그 판이 마지막 판이며 다음 판 전에 새로 섞습니다.
- 플레이어 → 뱅커 → 플레이어 → 뱅커 순으로 두 장씩 나누고, 바카라 룰(내추럴 8·9 / 플레이어 0~5 받고 6~7 스탠드 / 뱅커는 표에 따라)로 세 번째 카드를 필요한 만큼만 나눕니다. 승패는 실제로 나온 카드로 결정됩니다(슈퍼6 = 뱅커가 6점으로 승).
- 화면에 나온 배팅 쪽(플레이어/뱅커)에 맞춰 승리 · 패배 · TIE · SUPER6 버튼이 자동으로 눌립니다. 진행 중 실제 결과 빈도(괄호는 6덱 이론 확률)와 내 배팅 기준 빈도가 실시간으로 표시되고, "정지"로 멈출 수 있습니다.
- 6덱 이론 확률은 `node sim/exact_probs.js 6` 으로 전수 열거해 계산합니다(플레이어 44.6279% · 뱅커 45.8653%(그중 슈퍼6 5.3844%) · 타이 9.5069%). 같은 코드의 8덱 결과는 Wizard of Odds 값과 일치합니다.
- 게임이 끝나면 초기화 옆에 "재시도"(같은 설정으로 첫판부터 자동검증)와 "무제한 이어서 하기"(60 / 120 / 180판까지처럼 다음 60의 배수 판수를 골라 끝난 시점에서 목표 제한 없이 이어서 진행; 돈이 먼저 떨어지면 거기서 종료)가 나타납니다. 진행 속도는 게임 화면 우측 상단 "속도 1배 / 3배"로 고를 수 있고(1배 = 기본 속도, 3배 = 대기 시간·카드 간격이 1/3, 진행 중에도 바꿀 수 있음) 이어서 하기도 같은 속도를 따릅니다. 진행 중에는 "STOP" 버튼으로 이번 판이 끝나는 대로 멈출 수 있습니다.
- 메인 페이지에서는 자동검증·무제한 이어서 하기로 진행한 게임을 Supabase 통계에 저장하지 않습니다.
- 직접 진행(승리/패배 버튼)하는 일반 모드는 그대로입니다. 실제 카지노 결과를 눌러 입력하는 용도입니다.

## 카지노 로드 (구슬판 · 대로 · 중국점)

두 페이지의 게임 화면 아래에 판이 진행될 때마다 실제 카지노 화면처럼 자동 배팅법 선택(/2)은 대로 20×6 · 구슬판 10×6 · 중국점 3종 30×6, 메인은 가로 30칸 × 세로 6칸(구슬판은 20칸) 판이 그려집니다.

- 구슬판: 판마다 한 칸(파랑 P = 플레이어 · 빨강 B = 뱅커 · 초록 T = 타이 · 슈퍼6는 빨강 구슬에 6)
- 대로: 같은 쪽이 이기면 아래로, 바뀌면 오른쪽 새 줄, 세로 10칸을 넘으면 오른쪽으로 꺾음(용꼬리). 슈퍼6는 빨간 링 안에 6, 타이는 직전 칸에 초록 사선
- 중국점: 대로에서 파생된 큰눈이(1줄 전과 비교, 빈 원) · 작은눈이(2줄 전, 채운 원) · 바퀴벌레(3줄 전, 사선). 빨강 = 앞 줄 패턴을 따라감, 파랑 = 따라가지 않음
- 자동검증은 뽑은 실제 결과를 그대로, 직접 진행할 때는 배팅 쪽과 승리/패배로 실제 결과를 추정해서 그립니다(패배 = 반대쪽 승).
- 가로 30칸을 넘으면 가장 최근 30줄이 보입니다.

## 게임별 주소 (폴더)

메인 페이지에서 배팅방법을 고르면 그 게임의 주소로 이동합니다.

| 배팅방법 | 주소 |
|---|---|
| 슈퍼마틴 | `/supermartin` |
| 일반마틴 | `/classicmartin` |
| 파롤리 | `/paroli` |
| 1-3-2-6 | `/1326` |
| 달랑베르 | `/dalembert` |

각 폴더의 `index.html`은 메인 `index.html`의 복사본이며, `window.BCMK_GAME`으로 열리자마자 그 배팅방법의 세팅 화면(1p)으로 들어갑니다("← 배팅방법"을 누르면 메인으로 돌아갑니다). **메인 `index.html`을 수정한 뒤에는 `node sim/build_games.js`를 실행해 폴더 복사본을 다시 만들어야 합니다.**

## 일반게임 시뮬레이션 (/play)

메인 첫 화면의 "🎴 일반게임 시뮬레이션" 버튼으로 들어가는, 온라인 바카라를 혼자 하듯 즐기는 시뮬레이션입니다.

- 시작금액을 정해 입장하면 바카라 테이블이 나옵니다. 칩(1K · 5K · 10K · 50K · 100K · 500K · 1M)을 고르고 배팅 칸을 누를 때마다 그 금액이 쌓입니다. 플레이어 · 뱅커 · 타이 · 슈퍼6 · 플레이어 페어 · 뱅커 페어 모두 동시에 걸 수 있고, 취소 · 모두 지우기 · 이전 배팅 · 2배 버튼이 있습니다.
- 입장하자마자 6덱을 섞고 첫 카드 공개·소각까지 미리 마쳐 두며(컷카드에 닿으면 판이 끝난 직후 바로 새로 섞음), "시작(DEAL)"을 누르면 곧바로 카드가 한 장씩 나오고(소각, 컷카드, 세 번째 카드 규칙은 자동검증과 동일), 배당에 따라 잔액이 바로 정산됩니다. 한 판이 끝나면 곧바로 다음 판 배팅이 가능하고, 직전 판의 카드·배팅별 승패·합계는 "전판 결과" 패널에 따로 표시됩니다.
- 배당: 플레이어 1:1 · 뱅커 0.95:1(5% 수수료) · 타이 8:1 · 슈퍼6(뱅커가 6점으로 승) 2장 12:1 / 3장 20:1 · 페어(첫 두 장 같은 숫자) 11:1 · 타이일 때 플레이어/뱅커 배팅은 반환.
- 대로 · 구슬판 · 중국점 3종과 진행 기록이 함께 표시되며, 페어는 구슬판/대로에 작은 점(플레이어 페어 파랑 왼쪽 위, 뱅커 페어 빨강 오른쪽 아래)으로 나타납니다.
- `play/index.html`은 단독 파일입니다(메인과 별개). 로드·딜러 코드는 `2/index.html`과 같은 로직을 복사해 사용합니다.
